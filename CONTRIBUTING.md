# Contributing

Radarist v0.1 is published as a maintainer-owned reference prototype.

GitHub Issues are the sole inbound project channel. You may use an issue to
report a reproducible bug, request a clarification, or describe a feature need:

<https://github.com/radarist/radarist/issues>

The project does **not** offer a pull-request, patch-submission, contributor,
or maintainer-onboarding workflow for v0.1. Unsolicited changes should not be
expected to be reviewed or merged. The MIT license still permits you to fork,
modify, and redistribute the software under its terms.

When filing an issue:

1. use the current `main` snapshot;
2. include the command, expected result, and actual result;
3. include the operating system and Node/npm versions;
4. remove credentials, customer data, local paths, and private logs;
5. link a minimal reproduction when possible.

For vulnerabilities, follow [SECURITY.md](SECURITY.md). For usage questions,
follow [SUPPORT.md](SUPPORT.md). Participation in project spaces is governed by
the [Code of Conduct](CODE_OF_CONDUCT.md).
