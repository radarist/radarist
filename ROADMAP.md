# Roadmap

Radarist `0.1.0` establishes a local-first prototype for the workflow:

> signal -> entity -> relation -> radar -> report

## v0.1 priorities

- keep the seeded local demo understandable and reproducible;
- preserve human review and evidence visibility around AI output;
- keep quality, security, and generated-output checks deterministic;
- document prototype limitations without presenting planned work as shipped.

## Possible post-v0.1 work

- pin the opt-in build-sandbox image and executable tool bundle;
- reduce setup friction and improve cross-platform local operation;
- harden authentication, authorization, data isolation, and backups for any
  deployment beyond loopback;
- improve evidence quality, report review, and graph observability.

These are directions, not commitments or dates. GitHub Issues are the sole
place to report a need: <https://github.com/radarist/radarist/issues>.
