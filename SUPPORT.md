# Support

Radarist v0.1 is an unsupported reference prototype. It has no uptime,
response-time, maintenance, or compatibility SLA.

GitHub Issues are the sole inbound project channel:

<https://github.com/radarist/radarist/issues>

Before opening an issue:

1. read [Getting started](docs/getting-started.md),
   [Environment](docs/ENVIRONMENT.md), and [Limitations](docs/LIMITATIONS.md);
2. run `npm run doctor`;
3. reproduce on the current public `main` snapshot;
4. remove credentials, private data, and local filesystem details.

Include the failing command, expected and actual behavior, operating system,
Node/npm versions, and the smallest safe reproduction. Feature requests may be
filed as issues, but they are not delivery commitments.
